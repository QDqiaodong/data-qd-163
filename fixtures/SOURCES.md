本目录为原创虚构合成数据，使用MIT许可。没有真实个人、线上实验、生产日志、交易、项目进度或搜索用户信息；不来自外部平台。

`reconcile.json` 为计划执行核销自制样例：两条只发生一次的纽约 2024-11-03 01:30 计划规则（fold_policy 分别为 earlier/later），配一条纽约回拨墙上时间记录（两个候选 UTC）与一条 UTC 记录，演示最大配对如何把回拨记录固定到 later 实例。

`reminders/` 子目录为持久化提醒队列分支一联动流程的逐次输入（见该目录 README 与 `examples/demo_reminders.py`），全部为原创虚构数据，时间均为显式输入，不读取系统时钟。
